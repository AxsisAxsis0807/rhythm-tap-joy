# 忍者AdMax: ホーム／プロフィールへのインライン広告

調査日: 2026-10-28。**設定・配信互換性の確認待ち。実広告は無効。**

## 配置と実装

`RhythmHub` は `/` 内の `screen` 状態で画面を切り替える。`HomeScreen` の「公開された曲」セクションの後、`ProfileScreen` の編集フォーム／投稿曲一覧の後に `AdMaxBanner` を配置した。両画面の既存 `pb-28` が固定ナビゲーション用の余白を確保する。選曲・詳細・編集・プレイ・結果にはマウントしない。ゲーム判定・XP・Song Settings・プロフィール保存の処理は変更しない。

広告タグは、広告専用の `srcDoc` iframe に元のまま記載する。パーサーによる通常の script 読み込みなので、React 親文書への `document.write` やグローバル変数の混入を避ける。sandbox にはスクリプト実行とリンク先の別タブ表示のみを許可する。親文書へのアクセス・親画面遷移は許可しない。画面を離れると iframe ごと破棄し、子文書のタイマー・イベント等を終了する。再レンダーでは iframe を保持し、広告更新タイマー・自動再試行は設けない。戻った画面では新しい子文書になる。

確認した固定サイズをそのまま使用し、縮小・拡大・切り抜きをしない。幅が足りない場合は iframe を生成せず、広告リクエストもしない。広告失敗時の状態をゲームや認証の状態に接続しない。ResizeObserver 非対応環境でも広告を省略してゲームを維持する。

**この iframe/sandbox 方式の AdMax 公式な SPA 対応保証は確認できていない。** opaque origin のため、広告側のストレージ・参照元判定などに制約がある。モックの成功は実配信の互換性や収益計測を証明しない。互換性のために安易に `allow-same-origin` を追加して親画面の保護を外さない。

## 公式条件の調査

- [同じ広告タグを複数サイトに設置](https://www.ninja.co.jp/admax/help/faq/4279/): 許可される。収益最適化・レポート把握のため枠を分けることを推奨。本実装は同時に1枠のみ。
- [1ページに複数の広告](https://www.ninja.co.jp/admax/help/faq/4269/): 3枠まで推奨。別ページへの掲載数には制限なし。
- [PC枠作成](https://www.ninja.co.jp/admax/help/manual/10435/)・[スマホインライン枠作成](https://www.ninja.co.jp/admax/help/manual/10494/): サイズ・サイト属性・表示させない広告・URL等を枠作成時に設定する。一般サイトでも制限のチェックがなければアダルト広告が配信される。
- [枠修正](https://www.ninja.co.jp/admax/help/manual/10467/): オーバーレイの有無・表示させない広告・サイト情報は変更可能。広告サイズとサイト属性は変更不可なので、不適切な枠なら新しいタグが必要。
- [配信広告の選択](https://www.ninja.co.jp/admax/help/faq/4277/): 個別の広告は選べない。上記のアダルト・出会い等の制限以外に、任意カテゴリを除外できる公式手順は確認できなかった。追加制限が必要なら提供元への確認が必要。
- [AdMax規約](https://www.ninja.co.jp/rule/admax): 第10条は広告のはみ出し・要素の重なり・自己クリック・誘導・不正表示等を禁止している。広告は「広告」と表示し、操作ボタンから余白を取る。

## 未成年の運営者

確認した [AdMax規約](https://www.ninja.co.jp/rule/admax) および適用先の [忍者ツールズ共通規約](https://www.ninja.co.jp/rule/all) には「未成年」の明示条項を見つけられなかった。これをもって未成年が無条件に契約・報酬受領できると判断しない。他サービスである忍者広告マーケットの条件を AdMax の条件として流用しない。

一般的な契約条件として、未成年者は原則として法定代理人の同意が必要とされる（[法務省](https://www.moj.go.jp/seinen/chapter_02/commentary.html)）。未成年のサイト運営者の場合は、保護者の同意、登録・ポイント受取／交換に関する年齢条件を AdMax 提供元に確認してから利用する。運営者の年齢や同意の有無は本作業では推定・確認していない。
